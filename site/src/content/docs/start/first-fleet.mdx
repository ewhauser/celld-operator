---
title: Create your first fleet
description: Create an Ordered Bucket fleet with an explicit compatible runtime digest.
---

Complete [installation](../install/) and give `fleets/celld-runtime` access to a
new dedicated bucket. Choose actual zones in the bucket's region. This example explicitly pins the
published compatible fork; no runtime image default exists.

```yaml title="my-fleet.yaml"
apiVersion: celld.eric.dev/v1alpha1
kind: CelldFleet
metadata:
  name: my-fleet
  namespace: fleets
spec:
  profile: Bucket
  bucketWorkload: Ordered
  runtimeImage: ghcr.io/ewhauser/celld@sha256:4b9eb5656054580e7dd5ed2bbd9ee8b641ecd60c317437e9be63f4e3ae333f29
  replicas: 3
  serviceAccountName: celld-runtime
  storage:
    bucket: YOUR_DEDICATED_BUCKET
    region: YOUR_AWS_REGION
    sizeGiB: 10
  placement:
    azCount: 3
    zones: [YOUR_REGION_ZONE_A, YOUR_REGION_ZONE_B, YOUR_REGION_ZONE_C]
    mode: Strict
```

Apply it to your explicit context:

```bash
kubectl --context YOUR_CONTEXT apply -f my-fleet.yaml
kubectl --context YOUR_CONTEXT -n fleets wait celldfleet/my-fleet   --for=condition=InfrastructureReady=True --timeout=180s
kubectl --context YOUR_CONTEXT -n fleets rollout status statefulset/my-fleet --timeout=300s
kubectl --context YOUR_CONTEXT -n fleets get statefulset/my-fleet,service/my-fleet
kubectl --context YOUR_CONTEXT -n fleets get celldfleet my-fleet -o yaml
```

This Ordered Bucket fleet has temporary disks and runs celld directly; it
contracts by highest ordinal and restarts one member at a time. The default
Deployment layout lets Kubernetes choose each scale-in victim. Layout is
immutable after creation.

Look for three ready replicas, `Ready=True` and `Blocked=False`.
`InfrastructureReady=True` alone does not mean Pods have scheduled.
See [verification](../verify/) if the workload does not become ready.

The application Service uses port 8080. In-cluster clients need the label
`celld.eric.dev/client-of: my-fleet` in the fleet namespace. Internal port 8081
stays private. Continue with
[your first application](../first-application/).
