# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ewhauser/celld-operator/security/advisories/new).
Include the affected version, reproduction steps, impact, and redacted logs.
Do not disclose vulnerabilities in public issues or branches.

Security fixes target the latest release. The operator is experimental; a
successful local or Kind test does not establish AWS/EKS qualification.

The [release security guide](docs/release-security.md) describes publication,
artifact verification, repository controls, and the limits of those controls.
